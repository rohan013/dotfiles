# dotfiles

```
git clone https://github.com/rohan013/dotfiles && ./dotfiles/install.sh
```

Installs `CLAUDE.md` and `notes/` into a work directory (`~/work` by default, or pass one:
`./install.sh ~/projects/foo`), plus oh-my-zsh, iTerm2 (Menlo 15 profile) and fast key repeat.
Clone the session repo into the work directory and start Claude inside the repo.
No sudo. Run `./install.sh --dry-run` to see what it would do.
